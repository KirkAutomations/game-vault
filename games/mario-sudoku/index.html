How to Play / Cómo Jugar 🎮

🎯 Sudoku Rules

  • Fill every row, column, and 3×3 box with numbers 1-9
  • No number can repeat in any row, column, or box

🇪🇸 Spanish Challenge System

  • Tap a cell, then tap a number to place
  • You must answer a Spanish question to earn each number!
  • Correct answer = number placed + earn a coin 🪙
  • Wrong answer = no number + lose a coin
  • 0 coins = Study Mode (match words to earn coins back)

✏️ Notes Mode

  • Toggle notes to add pencil marks (no challenge needed)

🌟 Español Mode

  • Switch entire UI to Spanish for full immersion!

🇪🇸 Reglas del Sudoku

  • Llena cada fila, columna y caja 3×3 con los números 1-9
  • Ningún número se repite en fila, columna o caja

📚 Sistema de Desafío

  • Toca una celda, luego un número
  • ¡Debes responder en español para colocar cada número!
  • Correcto = número colocado + moneda 🪙
  • Incorrecto = sin número + pierdes moneda
